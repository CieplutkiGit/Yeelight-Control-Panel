HOW IT WORKS

Three steps. No cloud.

    Discover

    Find compatible devices using Yeelight LAN discovery.

  2. 2

    Connect

    Open a direct local connection to each device.

  3. 3

    Control

FOR DEVELOPERS

Build from source

Built with C++17, Qt 6 and CMake. Supports Windows, Linux and macOS.

  • C++17
  • Qt 6
  • CMake
git clone https://github.com/CieplutkiGit/Yeelight-Control-Panel.git
cd Yeelight-Control-Panel
cmake -S . -B build -DCMAKE_BUILD_TYPE=Release
cmake --build build --parallel
